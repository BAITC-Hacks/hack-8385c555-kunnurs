Отклонение текста схемой не доказывает устойчивость настоящей LLM к prompt injection. CORS не является авторизацией. Проверка отсутствия одной строки в `caplog` не доказывает маскирование всех ПДн в инфраструктуре.

Проваленных тестов нет. Проверены API-ошибки, входные атаки, неизменность данных и локальные Python-логи. Во время сетевого прогона логи сервера/прокси не подменяются клиентским caplog: эта часть подтверждена только in-process. Заражённый внутренний датасет и настоящий провайдер остаются вне проверенного объёма. Открытые препятствия: [OPS-PUBLISH и LEAD-LIVE-AI](blockers.md). Версия: OPS-изменения текущей ветки; точный hash см. в Git. Использован локальный origin http://127.0.0.1:32768; тестовый контейнер уже остановлен.
