# Синтетические данные

`city.json` перенесён из пользовательского PDF «Датасет районов — Google Документы.pdf», 5 страниц, полученного 23.09.2026. Все числа сохранены: 5 районов, 10 показателей, веса/доли населения, 14 мероприятий, 3 синергии и 3 несовместимости.

Показатели уже направлены одинаково: 100 — лучшее состояние. T1/T2 — транспорт, E1/E2 — экология, S1/S2 — соцсфера, B1/B2 — безопасность, C1/C2 — сервисы. Инвертировать «пробки» или «смог» ещё раз нельзя.

Данные синтетические, без ПДн. Идентификаторы районов латинские для API; русские названия отображаются пользователю. `version=hackalem-districts-v1` обозначает именно эту редакцию.

Источник истины — этот JSON. Резервный `contracts/examples/catalog.json` формируется LEAD скриптом `python -m scripts.export_contracts`. Если OPS меняет данные, запросить обновление версии, примеров и контрольных значений. Не менять числа ради красивого результата.

Ориентиры: исходный Score 52.55768; пример из PDF стоит 95 и даёт 56.54307. Исходные два критических значения — S1=38 и S2=35 в Нуре. Значение ровно 40 не критично.
