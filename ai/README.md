# Живой AI-анализ

Реализован адаптер OpenAI Responses API через Python SDK. Вход — рассчитанный SimulationResult и проверенный каталог. Выход LLM — три списка: сильные стороны, риски и рекомендации. Числовая сводка всегда формируется сервером.

## Настройка

Установить обновлённые зависимости из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Создать `.env` в корне, если его ещё нет, и добавить/изменить настройки. Существующий файл не перезаписывать, ключ никому не пересылать и не коммитить:

```dotenv
AI_MODE=live
OPENAI_API_KEY=<ваш ключ>
OPENAI_MODEL=gpt-4.1-mini
AI_TIMEOUT_SECONDS=12
AI_REQUEST_TIMEOUT_SECONDS=12
AI_CACHE_ENABLED=true
```

По умолчанию используются live и gpt-4.1-mini. Без ключа приложение работает с явным fallback. Приоритет имеют переменные окружения процесса; если в терминале ранее установлен `AI_MODE=mock`, удалить/изменить его. Ключ и модель из `.env` подхватываются при запуске backend: уже работающий сервер нужно перезапустить.

Конечная проверка реального провайдера (один вызов, не запускает сервер):

```powershell
.\.venv\Scripts\python.exe -m scripts.check_ai
```

Успех: `mode=live`, `source=provider`, `reason=null`, `score=56.54307`. Скрипт выводит только эти поля, не ключ и не текст ответа. Выходной код 1 означает mock/fallback. Запрос использует API-квоту аккаунта. Установка SDK и наличие ChatGPT сами по себе не подтверждают доступ к API.

Локальный backend у Куннура запускается на **8001**, так как 8000 занят Splunk:

```powershell
.\.venv\Scripts\python.exe -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8001
```

В отдельном терминале frontend:

```powershell
$env:VITE_API_URL = "http://127.0.0.1:8001"
npm.cmd --prefix frontend run dev
```

Открыть http://localhost:5173 и рассчитать исходный пример. В блоке объяснения должно появиться уведомление о настоящем AI-разборе. Режим конкретного ответа проверяется в `analysis.mode`; `/api/health` проверяет только заполненность конфигурации, не доступ к провайдеру.

## Поведение при ошибках

Deadline ограничивает весь вызов 12 секундами, включая ожидание повторов SDK. На одну попытку также максимум 12 секунд: медленный успешный ответ не обрывается преждевременно ради повтора. SDK допускает один повтор при временном сбое, если общий deadline ещё не истёк. Это укладывается в существующий клиентский таймаут 15 секунд. Ошибки ключа, модели, квоты, сети, таймауты и некорректный ответ приводят к HTTP 200 с неизменным расчётом и явным шаблонным fallback. Невалидные пять решений отклоняются до AI.

Есть кэш успешных ответов: до 128 записей на процесс, TTL час. Одинаковый результат/модель/версия промпта повторно не оплачивается при попадании в кэш; notice и source показывают источник. После рестарта кэш пуст. Это не гарантия отсутствия повторного запроса при одновременных обращениях к нескольким worker.

Отключить API полностью: `AI_MODE=mock`. Отключить кэш: `AI_CACHE_ENABLED=false`.

## Границы доверия

LLM не получает функций и не меняет выбранные меры. Она объясняет рассчитанное состояние; советы — варианты для последующей проверки. Ответ ограничен по структуре и длине; числовая сводка не доверяется модели. Выход с цифровыми числами/кодами отклоняется, однако семантическая корректность свободного текста не гарантируется одной JSON-схемой.

Текстовые поля перед отправкой маскируют email, телефоны РФ/КЗ и ИИН. Используется `store=false` и официальный endpoint; это не обещание нулевого хранения данных провайдером. В журнале приложения — фиксированный код fallback, без сырого ответа, промпта или исключения. Не включать HTTP/SDK debug-логирование на публичном сервере.

Тесты из `backend/tests/test_ai.py` используют реальный SDK и подменённый HTTP-транспорт, без внешних запросов и личных ключей. Живая проверка выполняется отдельно.

Реализация сверена по официальным источникам: [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs), [Python SDK: повторы и таймауты](https://developers.openai.com/api/reference/python), [GPT-4.1 mini](https://developers.openai.com/api/docs/models/gpt-4.1-mini).
