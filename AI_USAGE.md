# Использование Codex

## 23.09.2026 — первичная архитектура

Запрос пользователя: прочитать два PDF с ТЗ и датасетом, сразу создать архитектуру и отправить в GitHub. Пользователь ранее разрешил LEAD самостоятельно коммитить и пушить.

Codex извлёк весь текст 3 страниц задания и 5 страниц датасета через pypdf, перенёс численные правила, создал спецификацию, архитектуру, контракты, backend, mock AI, стартовый frontend, скрипты проверок и задачи команды. Исходные PDF не добавлялись в репозиторий. Внешние шаблоны приложения не копировались.

Принятое решение: подробные правила датасета имеют приоритет над неоднозначным требованием «5 решений по направлениям». Разрешены минимум 3 направления при максимуме 2 мер на направление; пример организаторов этому соответствует. Вся численная модель отделена от AI.

Подтверждены базовый Score 52.55768 и пример стоимостью 95 со Score 56.54307. Контроль включает ограничения бюджета/направлений/повторов/районов, все типы конфликтов, лаги, синергии, отрицательный эффект, clip, порог строго <40, все 120 перестановок примера и независимость запросов. 32 автоматические проверки прошли; React/Vite production-сборка прошла. Серверы и браузерное демо не запускались.

Ограничения: реальная LLM, e2e браузера, публичный деплой и база данных ещё не реализованы. При AI_MODE=live каркас честно возвращает fallback. Текущая версия — основа для работы команды, не завершённый продукт хакатона.
